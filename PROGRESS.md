Additionally, after a genuine autoplay block, pressing the play button started playback but nothing dismissed the notice. / 隐藏线路竞速胜出被换入播放器时会对旧主视频调用 `pause()`，中断其尚未完成的 `play()` 请求并产生 `AbortError` 拒绝；原处理只校验频道代数、不校验被拒的是否仍是当前视频，于是把这种"过期拒绝"误判为自动播放受限，在正常播放的画面上盖了提示。另外真实自动播放受限后，用户按下播放键画面恢复，但没有任何逻辑撤掉提示。

## Apple TV token racing subscription design / Apple TV 令牌竞速订阅设计（2026-11-18）

- Goal / 目标：one password/token subscription URL for any M3U player (Apple TV first); the player shows channel names, and selecting a channel makes the server race that channel's lines and transparently relay the winner. / 一条带令牌的订阅链接；播放器只显示频道名，点台即由服务端竞速线路并透明中继胜者。
- Tokens / 令牌：`IPTV_TV_TOKENS` in the private service environment (comma-separated, constant-time compare, revocation by edit+restart; empty disables the feature and the endpoints return 404). Token query auth applies only to the new external endpoints, never to the management API. / 令牌放私有服务环境变量，常数时间比较，改配置重启即吊销；留空即整体关闭。令牌只放行新端点，不适用于管理接口。
- Endpoints / 端点：`GET /tv/playlist.m3u?token=T[&view=main|supplement|english]` renders the library view with one entry per channel whose URL is an absolute `http://<Host>/tv/race/<view>/<channel_id>?token=T`. `GET /tv/race/<view>/<channel_id>?token=T` races the channel's ranked lines (concurrent manifest fetch, first line with a valid `#EXTM3U` manifest whose first segment returns data wins, ~10s budget), then proxies the winner through the existing final-URL rewriting; total race failure falls back to ranked line 0.
